# 紫白交界证据加强及图片复测

日期：2026-10-11。本页记录当时的加强与复测；2026-10-16起侧面也共用这一有效边界检查。当前规则见[边界与角点重构规则](安全区轮廓直线与角点重构规则.md)。

## 本次修改

保留紫色分割、普通白色分割和原有最近 1～2 像素相邻检查。在此基础上增加外侧区域的宽度、连续性和颜色核心检查，之后才允许边界点参与分段、拟合和求交。

1. 原轮廓点本身属于紫色；外法线 1～4 像素至少一半为白色，最近 1～2 像素内有白色。没有通过这一关，远处白色不能补足证据。
2. 沿切线取五个采样位置，半宽为 `max(1,min(6,2*s))`，`s=min(W,H)/480`；每个位置沿外法线向外采样，默认深度为 5 个原图像素。
3. 相邻列可能跨过轮廓像素阶梯，因此从第 3 像素开始检查条带连续性。默认允许一个孤立无效采样，但连续两个无效采样立即拒绝该列。至少三列通过宽度检查。
4. 另取白色核心：白色分割的 `S max` 限制为 `min(当前值,50)`，V 规则沿用。只统计已通过宽度检查的列，要求其外半段（默认第 3～5 像素）核心比例合计至少 60%。颜色证据按区域汇总，避免先逐列二值化造成跳变。
5. 内侧紫色仍为置信度权重，不增加固定的内侧宽度限制。有效点仍落在原紫色轮廓上。缺口不会补成绿色。

普通白色掩膜提供边缘混合像素容差，低饱和度核心提供更强的白色颜色证据。没有直接把所有蓝色 H 值排除，也没有越过物块去寻找远处白底。

参数位于 `boundary_geometry.BoundaryConfig`：`white_band_depth_px=5`、自动切线半宽、`minimum_white_lanes=0.6`、`minimum_white_core_support=0.6`。实时入口明确传入 `make_white_core_mask` 结果；仅传二值白色掩膜的兼容调用不能获得额外颜色信息。

深度是图像证据宽度，不是物理距离。本轮尝试过更深且逐列全白的检查，发现会跨入远处的印刷文字并大量截断真实边界，未采用该方案。当前也未放宽已有直线合并和角点求交规则来强行恢复候选。

保留候选相对原输出的最近位置差，中位数 0 像素、P95 约 4.79 像素、最大 7.21 像素。这里比较的是两版输出，不是对真实角点精度的测量。

## 自动验证

相关测试 68 项通过。其中新增 7 项覆盖：薄白色混合带、孤立白色射线、远处白色不能跨过近处颜色缺口、紧邻白色不能跨过后续两像素颜色缺口、孤立采样噪声、浅蓝受光面（正面/通用、左右镜像）以及偏暗冷色白底。

浅蓝受光面对照使用 HSV `(100,75,218)`：普通白色分割会通过，核心分割不会；加强后保留三个真实可见角点并补偿被挡角点。过曝后也接近中性的蓝色物块、真实白色遮挡物仍可能通过本规则，需要后续几何或语义证据，不能仅靠这次颜色检查保证物理外边界身份。
