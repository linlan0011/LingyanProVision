# 惯导位姿与安全区角点身份判断规则

本文说明当前程序怎样把输入的惯导位姿 `(x, y, 航向角)`、地图观察分区和相机检测到的有效角点结合起来，输出安全区编号及角点编号。规则实现位于 `safety_identity.py`，分区坐标在 `field_zones.json`，安全区几何和身份模板在 `safety_templates.json`；实时相机主循环位于 `purple_camera_segmentation.py`。

## 1. 坐标与编号

地图使用左下角为原点的毫米坐标系：X 向右增大，Y 向上增大。航向角采用逆时针正方向，`0°` 朝 +X，`90°` 朝 +Y；角度归一化到 `[-180°, 180°)`。

场地上半部安全区编号为 1，下半部为 2。安全区外框固定为：

| 安全区 | 地图范围 `(Xmin, Xmax, Ymin, Ymax)` | 地图角编号 |
| --- | --- | --- |
| 1 | `(1170, 1830, 2640, 3000) mm` | `.1` 西北、`.2` 东北、`.3` 东南、`.4` 西南 |
| 2 | `(1170, 1830, 0, 360) mm` | `.1` 西北、`.2` 东北、`.3` 东南、`.4` 西南 |

角点编号按地图固定，顺时针排列，不因相机画面左右翻转而改变。代码中 `map_corners()` 也按 `.1、.2、.3、.4` 的顺序返回地图坐标。

## 2. 位姿先命中哪个观察区

`field_zones.json` 将场地划为十个观察区。分区矩形包含边界，且其自身航向容差设为 `180°`，所以位姿命中分区时先看 X、Y；之后由身份模板单独检查更窄的航向范围。

| 观察区 | X 范围 (mm) | Y 范围 (mm) | 目标区/方向 |
| --- | ---: | ---: | --- |
| 1-W | 0–1170 | 2640–3000 | 安全区 1 西侧 |
| 1-E | 1830–3000 | 2640–3000 | 安全区 1 东侧 |
| 1-SW | 0–1170 | 1500–2640 | 安全区 1 西南斜视 |
| 1-S | 1170–1830 | 1500–2640 | 安全区 1 南侧正面 |
| 1-SE | 1830–3000 | 1500–2640 | 安全区 1 东南斜视 |
| 2-W | 0–1170 | 0–360 | 安全区 2 西侧 |
| 2-E | 1830–3000 | 0–360 | 安全区 2 东侧 |
| 2-NW | 0–1170 | 360–1500 | 安全区 2 西北斜视 |
| 2-N | 1170–1830 | 360–1500 | 安全区 2 北侧正面 |
| 2-NE | 1830–3000 | 360–1500 | 安全区 2 东北斜视 |

半场归属规则是明确的：`Y >= 1500 mm` 只能选安全区 1，`Y < 1500 mm` 只能选安全区 2。因此 `Y=1500` 属于安全区 1。即使两个矩形都包含边界，错误半场的模板也会被过滤。

位姿命中分区后还要满足该方向的模板航向容差。没有分区命中时显示 `no observation zone`；命中了分区但航向超出模板容差时，不建立该身份候选。程序取消了“观察点必须位于安全区横向外框投影范围内”的旧门限，因而安全区横向边界之外的斜视位姿也可以建立候选。

## 3. 观察方向对应的模板

方向模板的航向角和自动选择的视觉检测模式如下。角度比较使用环绕角差，例如 `179°` 与 `-179°` 的差是 `2°`。

| 方向 | 模板中心航向与容差 | 视觉检测模式 | 编号方式 |
| --- | --- | --- | --- |
| west（西侧朝东） | `0° ±35°` | `start-facing` 侧面 | 有向边模板 |
| east（东侧朝西） | `180° ±35°` | `start-facing` 侧面 | 有向边模板 |
| south（南侧朝北） | `90° ±35°` | `front-facing` 正面 | 有向边模板 |
| north（北侧朝南） | `-90° ±35°` | `front-facing` 正面 | 有向边模板 |
| southwest（西南斜视） | `45° ±45°` | `general` 通用 | 四点画面极值，缺角时位姿投影 |
| southeast（东南斜视） | `135° ±45°` | `general` 通用 | 四点画面极值，缺角时位姿投影 |
| northwest（西北斜视） | `-45° ±45°` | `general` 通用 | 四点画面极值，缺角时位姿投影 |
| northeast（东北斜视） | `-135° ±45°` | `general` 通用 | 四点画面极值，缺角时位姿投影 |

因此 `1-W、1-E、2-W、2-E` 使用原侧面检测器；`1-S、2-N` 使用原正面检测器；四个斜视区使用通用检测器。位姿模板决定的是待检安全区和检测模式，是否输出角点编号仍需通过后续的视觉角点规则。

## 4. 正面和侧面：有向边模板

视觉程序先从安全区分割结果中提取有效角点，再从角点附近、由白色场地支撑的有效边界段提取有向射线。射线从角点朝边界实际延伸的一侧定向；仅仅穿过角点的无限直线不能作为有效边。

在 640 像素图像宽度下，射线提取阈值为：角点到拟合线距离不超过 7 px，可见端点距离不超过 18 px，推断端点距离不超过 64 px，边段至少 8 px。不同图像宽度时这些长度按宽度比例缩放。两条候选射线的夹角必须在 `15°` 到 `165°` 之间。

有效射线方向使用图像坐标角：图像向右为 `0°`，向上为 `90°`，向左为 `180°`，向下为 `-90°`。四个局部位置需要满足以下方向组合：

| 局部位置 | 第一条射线（横向） | 第二条射线（纵深） |
| --- | --- | --- |
| 近左 `near_left` | `0° ±20°` | `45° ±35°` |
| 近右 `near_right` | `180° ±20°` | `135° ±35°` |
| 远左 `far_left` | `0° ±20°` | `-135° ±35°` |
| 远右 `far_right` | `180° ±20°` | `-45° ±35°` |

判断时会尝试两条射线的两种排列，以减少提取顺序带来的影响。各观察方向再把局部位置映射到地图固定角点：

| 观察方向 | 近左、近右、远左、远右映射的地图角 |
| --- | --- |
| west | `.1、.4、.2、.3` |
| east | `.3、.2、.4、.1` |
| south | `.4、.3、.1、.2` |
| north | `.2、.1、.3、.4` |

正面/侧面只有在所有有效匹配合并后恰好剩下一个角点候选时才输出名称；多解、无有效边或两个检测结果争用同一编号时显示 `?`。

## 5. 四个斜视区：位姿投影与四点联合规则

斜视时，图像里边的倾角会随观察位置和透视明显变化，所以程序不把斜视边角度硬套进正面/侧面模板。当前斜视模板有两种判断途径：

### 四个角都检测到时

若同一个分割目标中恰好有四个直接检测到的有效角点，程序根据四点的画面极值进行联合编号：找出最左、最上、最右、最下的四个不同检测点，再按该斜视区 `image_slots` 的顺序映射成地图角编号。

| 斜视区 | 画面最左、最上、最右、最下对应的地图编号 |
| --- | --- |
| southwest | `.1、.2、.3、.4` |
| southeast | `.4、.1、.2、.3` |
| northwest | `.2、.3、.4、.1` |
| northeast | `.3、.4、.1、.2` |

这个规则适用于一个检测目标中四个角都可见、且它们分别构成四个不同画面极值的情况。如果最左、最上等指向同一个点，不能组成完整映射，该帧回退到单点位姿投影。推断角不参与四点极值映射。

### 角点缺失时：单点位姿投影

对每个有效角点，程序用地图角坐标和惯导位姿计算该角在车体坐标系中的前向距离 `forward` 和左向距离 `left`。设位姿航向为 `θ`，地图角与车的位置差为 `dx, dy`：

```text
forward = cos(θ) * dx + sin(θ) * dy
left    = -sin(θ) * dx + cos(θ) * dy
预期方位 = atan2(left, forward)
```

只有 `forward > 0`（角点在车前）且预期方位处于相机水平视场内，角点才是候选。当前假设水平视场为 `110°`，也就是中心左右各 `55°`。

相机画面横坐标也会换算为方位角。640 像素宽时焦距近似值为：

```text
f = 图像宽度 / (2 * tan(水平视场角 / 2))
画面方位 = atan2(图像中心x - 角点x, f)
```

画面方位与地图角预期方位的环绕角差不超过 `18°` 时，该地图角进入候选。`horizontal_fov_deg` 和 `image_bearing_tolerance_deg` 在 `safety_templates.json` 的 `diagonal_pose_projection` 中配置。若得到唯一候选就显示编号；如果投影候选有多个或没有候选，就显示 `?`。

四点极值映射存在时，该组对应点优先使用极值结果；该点不再叠加单点投影候选。没有极值映射的角点才单独按位姿投影判断。

## 6. 结果如何显示，以及何时显示问号

每帧的识别流程可以概括为：

```text
惯导位姿
  → 命中地图矩形观察区
  → 按 Y=1500 mm 规则选安全区 1 或 2
  → 检查方向模板航向容差并自动选择视觉检测器
  → 分割安全区轮廓并提取有效角点/有效边界
  → 使用有向边模板（正面/侧面）或画面极值/位姿投影（斜视）
  → 唯一匹配才输出安全区.角点编号
```

例如 `1.3 SE` 表示安全区 1 的地图东南角。画面底部 `POSE candidates` 表示位姿给出的候选分区；`SAFETY ZONE` 和 `CORNERS` 是视觉匹配结果。斜视区在尚未识别角点时可以显示安全区来自位姿模板、角点仍为 `pending`。

以下情况会显示问号或不输出确认编号：没有检测到有效角点；角点附近缺少足够有效边（正面/侧面）；方向不符合局部模板；位姿投影不在视场或超出角度容差；存在多个地图角候选；两个检测结果得到相同角点编号；或当前图像旋转/灰度状态不符合身份模板要求。重复编号冲突会撤销所有冲突检测点上的编号。

若模板场景与相机当前检测模式不一致，自动模式会切换检测器；手动指定模式、非默认图像旋转或灰度输入可能使身份模板失效。安全区轮廓检测失败时，位姿只能提出候选，不能单独确认视觉角点。

## 7. 当前模板的适用范围

正面和侧面的角点方向阈值，以及斜视区的 `110°` 视场、`±18°` 方位容差，是当前工程配置。斜视四点映射以已提供的 `1-SW` 实时画面确立左/上/右/下对应关系；另外三个斜视区的映射按场地对称关系配置。相机俯仰、安装偏角、镜头畸变、目标高度、位姿误差和画面中角点分布都可能造成偏差，因此模板应在各实际观察区和航向范围内用实时帧校准。

此逻辑用于把视觉角点关联到地图编号，不会反向修正惯导位置或航向。
