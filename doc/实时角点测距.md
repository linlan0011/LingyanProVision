# 实时角点测距

当前新相机 ID：`usb0bda3035_1080p`。只使用同目录的内参和安装外参；安装外参必须绑定当前内参 SHA256。坐标原点和轴方向沿用安装标定：X 向前、Y 向左、Z 向上；输出单位为毫米，方位角单位为度。水平距离是到车体原点的距离，不是到相机光心的斜距，也不是场地绝对定位。

## 启动

先关闭棋盘采集、标定点采集和 Windows 相机，避免多程序同时取流。在项目目录运行：

```powershell
& ".\.venv\Scripts\python.exe" .\purple_camera_segmentation.py --camera usb0bda3035_1080p --ranging --target-z-mm 0 --scene auto
```

连同原来的选点／姿态主界面启动：

```powershell
& ".\start_app.cmd" --camera usb0bda3035_1080p --ranging --target-z-mm 0
```

默认不启用测距，原灵眼识别入口和识别规则不变。指定 `--ranging` 时必须明确填写 `--target-z-mm`。本次用户确认目标是地面交点，填 0；顶部角点必须改成实测高度。相机、镜头焦点或安装姿态改变后，重新标定相应参数。

## 画面与按键

- 角点旁的 `R1 r=...m` 对应下方测距表；若角点编号识别成功，会附带安全区角点编号。
- 表中 `X` 是前向位移，`Y` 是左向位移，`r` 是水平距离，`bearing` 向左为正。
- `R1` 等序号只在当前帧内对应，不是跨帧稳定跟踪 ID。
- 推断角点默认显示 `inferred_not_measured`，不输出距离。如明确需要测试推断角点，可加 `--range-inferred`，结果始终标记 `EST`，不要当作直接观测。
- `q`／Esc 退出；按 `s` 保存当前原图、预览及角点测距 JSON。测距快照位于项目 `照片/` 目录，每次有独立时间戳、原图和内外参哈希。

距离计算始终使用原始标定分辨率下的检测像素；只在最后缩小预览，不会拿缩放后的坐标计算。不会为了测距对整幅图去畸变，也不会调整已有分割／编号规则。

## 有效性限制

射线与目标平面夹角小于 3 度、交点不在射线前方、点在车体后方、像素无效时，不输出数字。默认最大水平距离 2000 mm，可通过 `--range-max-mm` 调整；这只是几何输出上限，不代表这个范围的精度已经验证。

本次独立验证仅覆盖地面 X=300～550 mm、Y=-100～100 mm，6 个手动点选点的平均误差 6.5 mm、最大 9.1 mm。自动检测点、其他距离／画面位置以及行驶时的精度尚未验证；应对实际识别目标继续用卷尺复核。

运行期间内外参文件被替换或删除，会停用测距输出并显示 `calibration_changed`。重新启动并核对安装状态后再使用。角点实际不在设定高度、安装发生移动、车辆俯仰变化等不能仅靠软件有效性检查识别。
