# 安全区下沿角点圆域匹配与仿真位姿融合

## 1. 本次实现范围

在 `安全区底边角点识别算法测试` 分支，继续使用已有颜色分割、有效边、拟合直线和可见/补偿角点算法。先执行上下沿分类，再对下沿候选进行地图身份匹配。

当前“融合”是使用仿真位置误差圆域和航向约束视觉角点身份，并输出视觉反算车位；画面显示 `1.2`、`1.3` 等地图固定编号。仿真输入仍作为先验，未实现真实传感器时序融合或自动改写输入位姿。

正面 `front-facing` 和通用 `general` 模式默认启用本流程。发车侧面 `start-facing` 保留原有检测和身份规则，测距上限同样使用1000毫米。

## 2. 参数和测距规则

| 参数 | 初值 | 调节方式 |
| --- | ---: | --- |
| 所有角点有效测距上限 | 1000 mm | `--range-max-mm`；两个启动入口和测距类默认一致 |
| 位置误差圆半径 | 200 mm | 用户确认的测试初值；参数窗口 `pose radius mm`，0～3000 |
| 可见点位置测量误差半径 | 30 mm | `map tol mm`，0～200 |
| 补偿点位置测量误差半径 | 50 mm | `infer tol mm`，0～200 |
| 图像视野边界余量 | 2 px | 当前代码初值 |
| 航向模型 | 圆域内固定先验航向 | 本次不引入航向扰动 |

可见/补偿测量误差半径是新增的可调测试参数，尚未通过实测误差统计验证；与上下沿分类的底边长宽容差是独立参数。

测距使用相机内外参，像素去畸变后与车体地面 Z=0 求交。距离定义为相对车体原点的水平距离 `r=hypot(X,Y)`，X向前、Y向左，包含相机安装偏移。

- `r≤1000 mm` 才能参与分类和地图匹配，1000毫米边界包含在内；仅预留浮点运算的微小数值容差。
- 直接点、补偿点、上沿假设点使用同一量程。上沿点的距离仍是Z=0投影距离，不是上沿真实三维距离。
- 超量程点仍在画面保留，显示 `OUT OF RANGE`，不参与最远/最近排序和地图身份匹配。
- 上下沿分类中的候选数量判断，改为按量程内候选数进行。只有1或2个时，仅将最近点标为下沿种子；超量程点仍保留在总数中，侧栏显示“有效数量/全部数量”。
- 接近地平线、像素越界、无前向交点、标定失效等其他测距失败，继续保守地停止该帧上下沿排序；不会把未知距离当成已知超量程。

## 3. 标定视野和圆域预筛

`CalibratedGroundView` 从当前相机内参、畸变系数及安装外参建立车体系地面视野。未使用旧模板的固定110°水平视场。

实现步骤：

1. 沿原始图像的四条边分别密集采样513个像素，使用对应针孔/鱼眼模型去畸变，获得空间射线。
2. 对归一化射线边界取凸包并向外预留余量，获得保守视锥包围区域。凸包可能保留少量实际图像边界以外的候选，因此该步骤只作预筛。
3. 将视锥约束变换到车体系，并与Z=0地面、相机前方、当前前视配置的车体前方相交。
4. 与1000毫米测距圆域相交。圆形使用128边外切多边形近似，避免内接近似误删范围内角点；实际观测仍按精确水平距离检查。
5. 根据先验航向旋转该地面区域，再平移到先验中心车位。
6. 判断每个地图底角距这个区域的最小距离是否不超过位置圆半径200毫米。等价于对圆域内所有可能车位的视野取并集，然后检查地图角是否位于并集内。

地平线以上的射线不必强行与地面求交，地面半平面裁剪可以处理当前相机上部朝向天空的情况。

地图上两个安全区的八个底角都先接受这一检查。只要某区至少一个底角可能进入视野，就保留该安全区候选；不会根据先验中心的 `Y=1500` 半场边界硬删除另一安全区。

自动检测模板使用圆域与观察分区的相交关系和航向约束。多个检测模式同时相容时，沿用中心模板或当前检测模式作为检测器选择，但新增地图身份匹配不依赖这个中心模板的角编号。

几何视野不包含物块遮挡分析。没有检测到的地图角不能因为“理论可见”就反过来否定其他匹配。

## 4. 下沿候选的地图范围

仅已有分类器标为 `LOW*` 或 `LOW`、且有效测距的点进入匹配。上沿 `UP` 和未分类点继续显示，不输出本流程的地图编号。

设先验中心位置为 `p0`，固定航向旋转矩阵为 `R`，观测点车体系相对位置为 `q_i`。该角在地图上的名义位置为：

`C_i = p0 + R*q_i`

其匹配范围采用以 `C_i` 为圆心、半径 `位置圆半径 + 测量误差半径` 的圆。对地图角 `M_j`，先检查：

`norm(M_j - C_i) ≤ prior_radius + measurement_tolerance`

并要求地图角没有被视野预筛排除。每个通过检查的地图角都是候选身份，而非立即确认编号。

这个计算等价于固定航向下平移车辆位置圆域，无需遍历圆内所有车位。

## 5. 多点联合匹配

对“观测i对应地图角j”反算名义车辆位置：

`p_ij = M_j - R*q_i`

每个匹配允许车辆位置位于以 `p_ij` 为中心、该点测量误差半径为半径的圆中。枚举匹配组合时同时要求：

1. 同一个地图角不能分配给两个不同观测点。
2. 一组匹配属于同一个安全区。
3. 先验位置圆和所有已匹配点的车位误差圆存在共同交集。

共同交集检查使用圆心及圆边界交点，不只检查两个圆分别相交；三个圆两两相交时也可能没有共同交集。

允许部分观测未匹配，以保留误检点或层级判断错误的解释。在联合相容组合中优先保留匹配数量最多的组合，数量相同的组合全部保留，不靠离先验中心更近来强行选择。

只有某个观测点在所有保留组合中均对应同一个地图角，且没有未匹配解释时，才显示地图编号。如果组合多解、争用同一地图角或反算车位冲突，则保留 `?`。搜索超出20000节点预算时，不根据截断后的结果确认编号。

只有一个下沿候选时，仍可凭200毫米先验圆域获得唯一身份；无法唯一确定时等待其他观测。

## 6. 画面和地图显示

相机画面保留蓝色轮廓、绿色有效边、红色拟合线及全部原始角点。黄色/品红中心分别表示直接/补偿角点；上下沿分类外圈继续沿用橙色UP、青色LOW*、绿色LOW。

新增地图身份直接显示在角点标签中，例如 `LOW* 1.3 EST`。上沿、未匹配或多解点显示 `?`，清除旧身份规则留下的编号。

仿真地图增加：

- 金黄色虚线圆：车辆位置误差圆域。
- 蓝色虚线：先验中心车位的地面视野。
- 紫色虚线：整个位置圆域的可能视野并集外轮廓；它是保守多边形显示。
- 灰绿色虚线圆：观测下沿点在地图上的匹配范围。
- 绿色/橙色地图角标记：已匹配的直接/补偿点编号。
- 青色叉号：已确认身份点反算出的名义车辆位置。

更改仿真位姿后，旧反馈会清除，等待新位姿对应的相机结果。地图界面仅显示回传，不自动改变或输出修正后的仿真输入。

## 7. 启动和输出

完整程序（显式指定参数，便于复现）：

```powershell
.\.venv\Scripts\python.exe .\run_app.py --camera usb0bda3035_1080p --ranging --target-z-mm 0 --range-max-mm 1000 --pose-radius-mm 200
```

相机脚本同样支持上述测距和圆半径参数，另可使用 `--ground-visible-tol-mm 30`、`--ground-inferred-tol-mm 50`。两个入口均可用 `--no-ground-association` 关闭新增地图匹配；下沿分类由原有 `--bottom-edge-test` 控制。

按P打开相机参数窗口，可调整 `pose radius mm`、`map tol mm`、`infer tol mm`。三个参数独立于HSV和底边长宽分类容差。

实时关联JSON和S键快照新增 `ground_association`，包括配置、可能安全区、每个地图角的预筛结果、下沿测量、匹配候选、反算位置、组合数量和搜索状态。

- `vision_vehicle_position_mm`：已确认身份点的名义反算车位平均值，未作时序滤波。
- `compatible_vehicle_position_mm`：一个满足保留组合误差圆共同约束的车位示例，不是概率最优估计。
- `pose_corrected=false`：尚未改写先验位姿。
- `identity_condition=conditional_on_lower_layer_and_prior_bound`：地图身份依赖下沿分类及位置误差范围假设成立。

真实运动中融合仍需要拍摄时间戳、同一时刻的惯导位姿及延迟补偿，本次静态/仿真身份匹配不能代替该部分。
