# 安全区侧面参数及规则（2026-10-16）

`start-facing` 表示安全区侧面预设。现在与正面 `front-facing`、通用 `general` 共用有效边检测、直线拟合、求交角点、测距、身份判断和视觉绝对位姿解算流程。`--scene auto` 根据适用位姿模板切换预设，也可手动指定模式。

## 侧面处理流程

1. 按所选相机的 HSV 参数分割紫色区域，使用 3×3 核开运算一次、闭运算两次；生成白色场地掩膜和中性色核心掩膜。
2. 以最大紫色区域为起点，选择面积合格且空间邻近的碎片，可通过中间碎片逐步连接，不再仅处理最大区域。
3. 沿真实轮廓逐点检查紫色归属、外侧白色带和中性色核心，得到有序有效边界段。黑色或有色遮挡面不能仅凭宽松白色阈值成为有效边。
4. 分段、拟合直线，并在限定间隔和残差下合并同边碎段。使用所选相机内参时，在校正像素坐标中拟合。
5. 从相邻有效支持边求交：真实连续交界产生直接角点；真实遮挡缺口两端满足向外延长、距离及质量限制时产生补偿角点。两条边无需水平或竖直。
6. 排除凹角、裁切造成的假角、平行边和不可靠交点。图像角度门限随支持边长度和拟合噪声变化，不再使用旧侧面固定20°～145°限制，也不再按邻近候选的图像高度保留较低点。
7. 显示和定位直接使用上述交点的同一对支持边，不再标点后按距离重新搜索边。定位采样取真实支持轮廓，不跨遮挡空隙补造样本。
8. 对直接及补偿角点进行Z=0投影测距，从最终标出点中选水平距离最近者；超量程或质量不合格时不换第二近点。
9. 使用输入位置默认200 mm误差范围、输入航向、标定视野和量程保留候选安全区，再以两条地面有向边匹配唯一地图角点。
10. 身份唯一后，根据已知地图边方向反算视觉航向，再由地图角点坐标及车体系角点坐标反算XY。地图显示独立的青色视觉位姿箭头和数据，输入位姿保持不变。

角点及位姿详细规则见[安全区轮廓直线与角点重构规则](安全区轮廓直线与角点重构规则.md)和[最近角点身份与视觉绝对位姿](最近角点身份与视觉绝对位姿.md)。

## 保留的侧面分割预设

| 参数 | USB 0BDA:3035 | LINGYAN / SeekFree |
|---|---:|---:|
| 紫色H范围 | 120～150 | 115～175 |
| 紫色S最小值 | 55 | 55 |
| 紫色V最小值 | 25 | 40 |
| 白色S最大值 | 179 | 179 |
| 白色V最小值 | 100 | 100 |
| 紫色区域最小面积 | 80 px² | 80 px² |
| 角点区域/碎片面积门限 | 400 px² | 400 px² |
| 支持边最短观测长度 | 12 px | 12 px |
| 亮度自适应 | 关闭 | 关闭 |

运行时P窗口参数可覆盖初值。侧面仍保留颜色与固定亮度设置；正面白色S阈值初值为80且启用亮度自适应。两者处理流程相同，参数预设可以不同。旧侧面相邻边比例长度、固定角度和近邻折点分组参数不再参与实时主循环。

## 显示与启动

蓝线为紫色轮廓，绿线为有效紫白边界观测，红线/L#为拟合边组；黄点为直接角点，紫红点为补偿角点，青色圆环标记真实测距最近点。已知地图身份时显示编号。定位量程默认1000 mm，身份、地面正交和双边航向一致性容差默认各15°。

```powershell
.\.venv\Scripts\python.exe run_app.py --camera usb0bda3035_1080p --scene start-facing
```
