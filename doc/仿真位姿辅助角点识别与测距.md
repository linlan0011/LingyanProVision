# 仿真位姿辅助角点识别与测距（方案一）

## 当前做的是什么

地图 UI 中手动选择的车辆位置和航向是**仿真位姿先验**，不是硬件 IMU 数据。
流程为：仿真位姿 → 观察分区与识别场景 → 视觉边界匹配 → 安全区/角点编号 → 已标定相机测距。
相机结果回传地图窗口用于显示，**不修正车辆位姿，不写回先验，不进行 EKF 融合**。

已知地图保存在 `safety_templates.json`，观察分区保存在 `field_zones.json`。
上方安全区为 1，下方为 2；每个安全区从地图西北角顺时针编号：`.1` 西北、`.2` 东北、`.3` 东南、`.4` 西南。
地图尺寸和安全区边框位置必须与实物一致，仿真位姿也应与相机所在车辆的大致位置、朝向一致。

## 启动

先关闭 Windows 相机、标定采集和其他占用摄像头的窗口。已导出标点数据无需重做。
在 `C:\Users\24435\Desktop\LingyanProVision` 的终端运行：

```powershell
& ".\start_app.cmd" --camera usb0bda3035_1080p --ranging --target-z-mm 0
```

也可以双击 `start_sim_pose_ranging.cmd`，或在 VS Code 选择
`Simulated pose + calibrated ranging (USB 1080p)`。
两个窗口会一起启动：地图位姿选择器、相机识别与测距窗口。关闭地图窗口或在相机窗口按 `q` / Esc 都会结束本次联动。
需要使用另一台已标定相机时，将 `--camera` 改为对应相机 ID；程序会检查该相机内外参及其绑定关系，不借用其他相机的标定。

## 怎么操作

1. 保持相机安装位置、镜头、分辨率和旋转方式与标定时一致，把画面对准地面安全区外边框。
2. 地图上单击设置位置，按住左键拖动设置航向；也可在右侧输入 X、Y、航向。保持“实时输出位姿”勾选。
3. 地图位姿同步到 `selected_pose.json`，识别程序自动选择分区和场景；没有匹配分区、航向不合适或视觉证据不足时，不强行编号。
4. 相机窗口显示角点编号以及车体坐标下的 X、Y、水平距离 r、方位角。`?` 表示身份未确认；此时可能仍有相对测距，但不能把它当作某个已知地图角点。
5. 地图上绿色圈表示直接可见且已编号的角点，橙色圈表示已编号的推断角点。右侧显示最多两个直接可见、已编号点的距离。圆圈标在**已知地图角点位置**，并不是视觉计算出的新车辆位置。
6. 修改位姿后，旧视觉回传立即不再显示。收到当前位姿的新结果后再显示；过期、另一相机或上次运行的结果不会作为本次反馈。
7. 在相机窗口按 `s` 保存当前帧、标注预览和测距 JSON，方便对照卷尺数据。推断点默认不输出真实测距。

## 坐标和参数

地图坐标：原点在场地左下角，X 向右，Y 向上；0° 向右，90° 向上，逆时针为正。
测距坐标：原点是外参标定使用的**车体原点**，X 向前，Y 向左，Z 向上；距离单位均为毫米。
两者不是同一个坐标系，不可直接把车体 X、Y 填入地图位置框。

当前地面角点指定 `Z=0 mm`。测距读取所选相机 `calibration/results/<camera>/intrinsics.json` 和 `mount_pose.json`，按照去畸变、视线旋转、与地面求交的方式计算。
斜视缺角需要投影辅助编号时，在当前 Z=0 测距模式下使用真实 K、畸变和安装外参，而不是旧版约 110° 的视场估计。原有正面/侧面边界规则和完整四角的图像极值编号规则保持不变。

默认拒绝接近地平线、射线不朝向地面、车体后方和超过 2000 mm 的测距。2000 mm 只是软件上限，**不是精度承诺**。
此前近距离的 6 个手工点验证（X 约 300–550 mm、Y 约 ±100 mm）平均误差约 6.5 mm、最大约 9.1 mm，这是历史结果。
当前精度应以该相机最新的 `range_validation.json` 及其标定文件绑定为准；不能根据近距离结果保证远处自动角点达到同样精度。继续补充不同距离、左右偏移处的独立验证点。

## 文件与排查

- 仿真位姿输入：`selected_pose.json`。
- 当前视觉回传：`output/association/usb0bda3035_1080p/latest.json`，与输入分离，不反写位姿。
- 相机运行日志：`output/logs/vision_*.log`。
- 旧相机的标定仍在各自相机目录下；联动功能不修改任何相机的标定结果。

看得到紫色边框但没有编号时，先核对地图位姿、航向和观察分区，再检查角点是否直接可见、两侧边界是否满足识别条件。
编号正确但距离不对时，检查是否真的是地面交点、安装姿态是否改变，再在对应距离用卷尺做独立验证。
本功能不会因为已有地图就从任意单个像素推断可靠的车辆全局位姿。
