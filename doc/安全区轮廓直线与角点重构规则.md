# 安全区轮廓、直线与角点重构规则

2026-10-10。适用于 `front-facing` 与 `general`。实现位于 `boundary_geometry.py`，实时入口为 `purple_camera_segmentation.py`。`start-facing` 保留已完成的侧面规则。

## 流程及 OpenCV 方法

1. 沿用每台相机、每个场景的紫色和白色颜色分割参数，以及原有开闭运算。
2. `findContours(RETR_EXTERNAL)` 取得紫色区域外轮廓；在每个轮廓的局部掩膜中用 `CHAIN_APPROX_NONE` 恢复逐像素、按绕行顺序排列的点。
3. 在原图像素坐标中逐点检查紫白相邻关系，保留有效观测段。
4. 有匹配内参时，用 OpenCV `undistortPoints` 校正边界点，转为保留内参尺度的去畸变像素坐标。只校正点，不重采样整幅彩色图。
5. 对每条连续有效观测段分别执行 `approxPolyDP`，形成局部近似直边；初步和最终直线均使用 `fitLine(DIST_HUBER)`。
6. 检查方向、垂直位置、白色所在侧及沿线间隔，合并同边碎段；每次合并重新检查整组。
7. 只对有轮廓邻接关系或相对开放端的边求交，区分可见角点和补偿角点。
8. 交点与支撑边端点映回原图像素，再交给既有身份判断和测距模块，避免重复使用去畸变坐标进行测距。

未找到匹配内参时，使用原图像素拟合，不借用其他相机的标定。广角畸变此时可能使一条边分成多组。

## 有顺序的含义

每个紫色连通区域各有一个外轮廓序列：`P0 → P1 → … → Pn-1 → P0`。相邻点为水平、垂直或对角相邻像素。顺序是沿边界绕行，不是按 X/Y 排序；起点不保证是物理角点。

用 `contourArea(..., oriented=True)` 判断绕行方向。对局部切线计算指向区域外侧的法线。不同区域的点不能直接首尾拼接。

## 紫白相邻判据

- 以轮廓点前后最多 4 个采样位置计算局部切线，减少像素阶梯引起的方向抖动。
- 沿外法线在原图约 1、2、3、4 像素处采样。白色样本还必须不属于紫色掩膜。
- 至少一半采样为白色，并且最近 1～2 像素内至少有一个白色采样；点本身必须属于紫色。
- 2026-10-11 增加外侧白色区域证据：沿切线放置五条平行外法线采样列，半宽为 `max(1,min(6,2*s))` 像素，默认向外检查 5 个原图像素。最近相邻判据仍单独通过，不能用远处白色替代。
- 为避免相邻采样列落到轮廓像素阶梯的内侧，从每列第 3 像素起检查宽度/连续性。默认允许一个孤立无效采样，但连续两个无效采样立即使该列失败。至少 60% 的列需通过。该检查不绘制采样区域，也不向紫色轮廓外移动绿色线。
- 另外生成白色核心掩膜：复用白色分割函数，但令 `S max = min(当前 white S max,50)`，V 规则与当前白底分割一致。通过宽度检查的列中，外半段（默认第 3、4、5 像素）的白色核心比例合计至少为 60%。普通白色掩膜用于混合边缘容差；核心掩膜提供低饱和度颜色证据。
- 代码参数在 `BoundaryConfig.white_band_depth_px`、`white_band_half_width_px`、`minimum_white_lanes`、`minimum_white_core_support`；只在正面/通用流程启用。侧面流程不使用新增检查。单独调用 `detect_boundaries` 时需传入 `white_core_mask` 才有颜色核心检查；仅有二值白色掩膜时只能验证空间证据。
- 内侧同样采样紫色，形成支持置信度。内侧不强制具有固定宽度，避免删除远处只有一两像素宽的尖角。
- 图像最外侧裁切边不作为有效观测。
- 不向外搜索十几像素、不越过宽黑边找白色，也不因整段的平均支持率通过就把整段染绿。

绿色只画真实有效轮廓点。拟合越过的缺口不补成绿色。宽度为图像像素宽度，并非实测场地尺寸；没有强行按分辨率扩大纵深，以免跨入远处印刷文字或其他物块。过曝后饱和度也低于 50 的蓝色/白色物块仍可能通过，不宣称已经获得白色底板的语义身份。

## 分段、合并与拟合参数

定义 `s = min(图像宽, 图像高) / 480`，`m = corner min side`，默认 12 像素。

| 参数 | 当前值 |
|---|---|
| 局部轮廓近似 epsilon | `max(1, 2.4*s)` 像素 |
| 拟合误差容差 t | `max(1.5, 3*s)` 像素 |
| 方向基础容差 | 8° |
| 短段方向附加容差 | 分离碎段允许 `atan(2*t / 较短段长度)`，总容差最多 25°；同轮廓共享端点的相邻段保持基础 8°，避免吞掉真实转折 |
| 白色外法线一致性 | 两单位法线点积不小于 0.8 |
| 双向垂直位置检查 | 双方端点到对方直线距离不超过 `2*t` |
| 合并后各成员误差 | 每个成员点到最终线的距离第 90 百分位不超过 `t` |
| 相邻碎段允许间隔 | `max(4*m, 0.75*(两段长度之和))` |

1920×1080 时，epsilon=5.4 像素，t=6.75 像素。这些是当前实现值，允许结合实际样本再调整；不是定位精度承诺。

方向、垂直位置与白色侧向需要整组所有成员相容。沿线间隔只要求能通过相邻碎段连接，不能要求一条长边最远两段之间仍只有一个小间隔。后来的中间碎段可以连接两个原先分开的同边组。

不同的完整闭合紫色区域不当作同边遮挡碎片合并。同一边组的拟合点始终来自真实有效轮廓，不使用补出的虚拟点。输入局部点集后，`fitLine` 只拟合一条线；多边分组由上述规则完成。

## 角点规则

- 线组的总观测长度至少达到 m，拟合误差通过检查。
- 同一轮廓按原顺序检查相邻线组；拒绝内凹遮挡转折。
- 检查交点到两侧实际支撑端点的关系，拒绝线段中部的无关交叉。
- 角度采用朝实际可见支撑段的两条射线计算。基础范围为 5°～175°，另外根据 `atan(2*max(0.5,拟合误差)/观测长度)` 累加两条线的方向不确定度；短噪声段不足以证明浅转折，长边仍允许很钝的透视角。
- 可见角点：两侧之间是连续有效转折，局部过渡弧长不超过 `max(2*m,4*t)`，交点到端点偏移不超过 `4*t+过渡弧长`。
- 仅一个采样无效且转折弧长不超过 `2*t` 时，按像素级采样误差处理；该点仍不染绿。
- 很短的结构过渡段若两端均未形成可靠角点，可以尝试两侧更长支撑边的交点；仍需通过连续性、偏移和外推检查，不要求完整四边形。
- 补偿角点：真实有效段之间存在缺口，交点朝向开放端，两条边外推距离均不超过 `max(m, 两条线组观测长度的较小值)`；裁切边不用于推测。
- 跨区域求交只允许无效边界旁的开放端组合。独立闭合绿色轮廓不互相补偿。
- 同一位置按 `max(3,min(10,0.5*m))` 像素半径去重，优先保留可见点。

没有“必须看到完整四边形”“必须水平长边”“只能有两个角点”或整幅图宽高比例角点长度门槛。

## 显示

- 蓝色：紫色分割的真实外轮廓。
- 绿色：逐点通过紫白相邻检查的真实观测段。
- 红色 `L#`：独立拟合的边界组；同一编号可跨越局部遮挡缺口。
- 黄色：可见角点；紫红色：补偿角点。
- 青色圆环：既有相对较近的定位候选；地图编号仍由原身份模块判断。

红线在去畸变坐标中是直线。映回有畸变的原图后可能略弯曲，这是坐标映射结果。绿色始终位于原蓝色轮廓上，红线允许存在拟合误差，并允许越过缺口。不显示橙色多边形。

## 验证与限制

测试与回放位于 `tmp/boundary_refactor_20261010/`，相关测试涵盖外轮廓/内侧白区、多个遮挡缺口合并、黑色相邻边拒绝、左右镜像补偿、分离区域、平行边、裁切、标定坐标往返及旧侧面/身份/测距兼容。

颜色判据不能保证排除与白底相连的白色遮挡物。遮挡使内侧区域与外部贯通时，`RETR_EXTERNAL` 也不能单独保证物理外边身份。当前输出是几何角点候选，不自动等于地图上唯一的四个角。连续帧中颜色掩膜变化可能导致可见/补偿类别切换；当前没有增加时间滤波，也没有完成运动定位精度验收。

OpenCV 参考：[轮廓与直线拟合](https://docs.opencv.org/4.x/d3/dc0/group__imgproc__shape.html)、[标定与畸变校正](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)。
