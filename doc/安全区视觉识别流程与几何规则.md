# 场地安全区视觉识别流程与几何规则

> 2026-10-10：正面和通用流程已重构。当前有效规则见[安全区轮廓直线与角点重构规则](安全区轮廓直线与角点重构规则.md)。本文对应之前版本；侧面规则仍参照专门文档。

> 2026-10-09更新：正面和通用主流程已改为[正面及通用角点识别简化规则](正面及通用角点识别简化规则.md)。本文正面部分保留为历史流程参考；侧面流程仍适用。橙色拟合框已停止显示。

本文说明电脑端 OpenCV 原型中两种安全区视角的识别流程：

1. `start-facing`：车辆刚离开发车区，车头正对安全区侧边。
2. `front-facing`：车辆正对安全区。

当前 LINGYAN 配置对应龙邱灵眼 Pro、USB 索引 `0`、`640 × 480`、不旋转图像。场景可以通过命令行固定，也可以由 `--scene auto` 根据已配置的位姿区域模板选择。位姿模板负责选择观察视角和后续角点身份关联；下面先说明图像中的边界与角点几何检测。

## 1. 两种模式共用的图像处理

### 1.1 紫色区域分割

原始 BGR 图像先转换为 HSV，再按紫色阈值生成二值掩膜。LINGYAN 两个模式的初始阈值相同：`H=115～175`、`S≥55`、`V≥40`。低于 `min area=80 px²` 的连通区域不进入后续候选。

对紫色掩膜使用 `3 × 3` 结构元素，先开运算 1 次，再闭运算 2 次。开运算去除小噪声，闭运算连接小的分割断点。蓝线画的是处理后紫色掩膜的实际外轮廓。

### 1.2 白色场地掩膜

紫色轮廓只有在其外侧紧邻白色场地时，才视为安全区有效边。白色掩膜结合饱和度、亮度和色相：排除高饱和暖色物块；低饱和中性色可按亮度阈值进入掩膜；低饱和、略暗的中性像素允许比白色亮度门槛低最多 20，以适应远处偏暗的场地。

LINGYAN 两种模式的白色初始参数不同：

| 参数 | `start-facing` | `front-facing` |
| --- | ---: | ---: |
| `white S max` | 179 | 80 |
| `white V min` | 固定 100 | 随曝光调整为 80～100 |
| 紫边显示为绿边的最低支持率 | 0.40 | 0.35 |

判断白色支持时，沿紫色轮廓外法线向外找第一个非紫色位置，再检查其外侧 2、4、6、8 像素处；每个采样位置至少有两处为白色才算通过。沿整段多点采样，计算白色支持比例。这样黑色或有色物块紧贴紫边时，该处通常仍保持蓝色。

正对模式根据画面下部低饱和场地的亮度调整紫色 `V min` 为 20～40、白色 `V min` 为 80～100。侧面模式使用固定阈值。

## 2. `start-facing`：正对安全区侧边

该模式对左右两端采用对称规则。发车位置可能在场地不同一侧，图像中的左端与右端均使用同一组几何条件。

### 2.1 处理流程

```text
HSV 紫色分割
→ 开闭运算并提取紫色外轮廓
→ 用紫白外侧支持确定绿色有效边
→ 仅在最大紫色区域内寻找凸角
→ 合并同一端相邻候选，只留较低的点
→ 依据图像纵坐标选取相对较近的定位候选
```

侧面模式只允许最大合格紫色连通区域产生角点。更小区域仍可显示蓝色轮廓，但不生成黄色角点。

### 2.2 直接角点约束

候选角点必须满足：

- 位于紫色外轮廓的凸角，不接受内凹缺口。
- 不接触画面边缘，避免图像裁切产生假转角。
- 两条相邻轮廓边的白色支持率都至少为 `0.40`。
- 两条相邻边的长度分别不小于：

  ```text
  max(12 px, 外接框较短边的 12%, 轮廓周长的 1.2%)
  ```

- 两边夹角在 `20°～145°`。
- 对轮廓使用周长的 `0.8%、1.2%、1.8%、2.5%、3.5%` 多种近似精度，合并重复候选。
- 同一端水平相距约 `32 px`、纵向相距约 `64 px` 的候选归为一组，只保留图像中较低的点。

侧面模式不延长有效边推算被遮挡角点。没有足够可见的紫白边时，不输出该角点。

## 3. `front-facing`：正对安全区

正对模式处理安全区边框被一个或多个物块遮挡的情况。它先沿真实蓝色轮廓识别绿色有效边，再拟合直线、组合分散边段，并区分直接角点和遮挡补偿点。

### 3.1 紫色分块关联

物块可能把同一安全区边框分成多个紫色连通区域。正对模式从最大区域开始，按邻接关系扩展到可能属于同一边框的较大区域。候选区域面积至少为 `max(400 px², 最大区域面积的 25%)`；水平间隔不超过画面宽度的 `16%`（640 像素画面约 `102 px`），且垂直方向要有足够重叠或中心高度接近。

这一步允许后续几何处理跨越被物块隔开的区域，但本身不会把任意远处的紫色噪声并入安全区。

### 3.2 绿色有效边与橙色拟合边

绿色有效边严格沿蓝色分割轮廓绘制。程序从同一轮廓段的蓝色边界点拟合直线，因此绿色标记本身不会用端点弦线切过拐弯或缺口。

正对模式显示绿边的白色支持率门槛为 `0.35`。直接角点确认采用更严格的 `0.40`。从绿色轮廓采样点拟合出的直线以橙色表示：

- 方向差不超过约 `10°`；
- 两条拟合线垂直间隔不超过 `max(6 px, 图像较短边的 1.8%)`；
- 沿线方向的断开距离不超过 `max(40 px, 图像宽度的 16%)`；
- 形成橙色多边形边的合并线段长度至少为 `max(20 px, 图像宽度的 6%)`。

因此，彼此共线、间隔有限的多段绿线可以合并为一条橙色拟合边；很短的过渡边不会单独成为多边形边。连续绿边上的弯折则保留在原始蓝绿轮廓上，用相邻拟合线的交点判定直接角点。

### 3.3 黄色：直接观察到的角点

黄色直接角点来自两条绿色有效边各自拟合后的直线交点。两边必须由同一条连续的绿色轮廓链连接；中间可以有短过渡段，但其长度不超过 `max(24 px, 图像宽度的 6%)`。若绿色链已经连续形成转角，程序标黄色角点，不生成该处的紫红色补偿点。

两条主体拟合边还要满足：长度至少 `max(20 px, 图像宽度的 6%)`；最近端点距离不超过 `max(30 px, 图像宽度的 12%)`；夹角在当前相机配置的 `15°～145°` 范围内；拟合交点位于画面内或画面边缘附近。

### 3.4 紫红色：遮挡角点补偿

仅当支持角点的有效绿边之间存在真实断口时，才允许由拟合线延长求补偿角点。程序会拒绝同一连续绿边链上的候选，并检查边长、交角、断口距离、延长距离、近侧边方向和白色支持率。

用于推算的近侧边需要大致水平，且长度至少为 `max(20 px, 合并区域宽度的 25%)`。普通缺口和较宽遮挡使用不同延长约束；宽遮挡只有在侧边足够长、近侧边支持率较高时才会放宽。所有候选交点还要位于合并安全区区域附近、靠近图像中的场地近侧，并避开已确认可见角点。

如果同一物理角点区域同时出现黄色点和紫红色补偿点，或出现多个相近补偿点，最终每个区域只保留一个结果；有合格补偿点时保留补偿点，表示真实角点被遮挡。

### 3.5 橙色：补齐多段缺失边并拟合多边形

橙色边由绿色轮廓采样点拟合。共线且间隔有限的绿段先合并；随后仅连接端点足够近、交角足够明显的相邻拟合边。限制交点距离、线段延长长度和角度，是为了防止把梯形的对边误连成三角形。

橙色多边形用于表示基于有效绿边得到的几何拟合结果；它可以跨越有限的遮挡缺口，但绿色仍只表示蓝色边缘上已验证为紫白相接的部分。

## 4. 相对近点与位姿模板

黄色直接角点和紫红色补偿角点均可进入定位候选筛选。以图像纵坐标最大的候选为当前相对近点；纵坐标距离不超过 `near band %` 的点都可同时加青色圆环。默认值为 `10%`，在 480 像素图像高度下约为 `48 px`。这是固定相机视角下的图像距离代理量，不是标定后的地面距离。

应用可通过 `--scene auto` 根据当前位姿、观察分区和航向模板选择 `start-facing`、`front-facing` 或 `general`。显式传入场景名时则固定使用该场景。角点的地图编号关联属于检测后的身份识别步骤；它读取位姿模板和有效边方向，不改变前述紫色分割与几何角点规则。

## 5. 颜色标记

| 颜色 | 含义 |
| --- | --- |
| 蓝色 | 紫色二值掩膜的外轮廓 |
| 绿色 | 沿蓝色轮廓绘制、并通过紫白邻接判定的有效边 |
| 橙色 | 由绿色轮廓点拟合、合并或延长得到的直线/多边形边 |
| 黄色 | 连续有效边拟合后的直接角点 |
| 紫红色 | 绿色有效边在真实断口处延长求出的补偿角点 |
| 青色圆环 | 落在相对近点范围内、可作为定位候选的角点 |

## 6. 当前相机配置与运行方式

本文数值以 `--camera lingyan` 的灵眼 Pro 配置为准。彩钻风 Pro 使用独立的 `--camera seekfree` 配置，采集分辨率、旋转和部分正对模式近似参数不同；更换相机、镜头或照明后需重新核对现场效果。

```powershell
# 固定运行侧面模式
.venv\Scripts\python.exe purple_camera_segmentation.py --camera lingyan --scene start-facing

# 固定运行正对模式
.venv\Scripts\python.exe purple_camera_segmentation.py --camera lingyan --scene front-facing

# 根据位姿模板选择模式
.venv\Scripts\python.exe purple_camera_segmentation.py --camera lingyan --scene auto
```

参数定义和处理实现以 [purple_camera_segmentation.py](../purple_camera_segmentation.py) 为准；侧面模式的历史实拍参数另见 [安全区侧面参数及规则.md](安全区侧面参数及规则.md)。运行预览时按 `s` 保存同一时刻的原始帧和标注帧，便于复核阈值和角点误判。
